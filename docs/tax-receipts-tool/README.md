# Tax Receipts & Contributions Tool docs

This folder, with the code in [`apps/tax-receipts/`](../../apps/tax-receipts/),
is the source of truth for the Tax Receipts & Contributions tool.

- [`architecture.md`](architecture.md): code layout, how to run it, and how
  the main mechanisms work.
- [`user-guide/`](user-guide/README.md): what the tool does and how to use
  it, area by area, for the people who use it.
- [`ui-patterns.md`](ui-patterns.md): table, modal, and button conventions for
  the web app's list screens.

Elections Ontario rules are checked against EO's own published requirements
and guidance, with the source and date noted where a doc relies on them.

This repo is public. Internal strategy, stakeholder detail, and vendor
material shared in confidence (including Qomon's API specs) do not belong
here.
