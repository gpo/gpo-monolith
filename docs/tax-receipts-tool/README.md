# Tax Receipts & Contributions Tool docs have moved

The project knowledge base for the Tax Receipts & Contributions tool (design,
glossary, Elections Ontario compliance rules, Qomon and warehouse integration
notes, decision log, and open questions), along with the confidential Qomon
OpenAPI specs, now lives in the **private** `gpo/qomon-migration-documents` repo
under `tax-receipts/` (engineering docs in `tax-receipts/design/`, specs in
`tax-receipts/design/qomon/`).

They were moved out of this public repo because they include internal strategy,
stakeholder detail, and vendor material shared in confidence. Ask the tech team
for access.
