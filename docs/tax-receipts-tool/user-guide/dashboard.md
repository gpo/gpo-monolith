# Space dashboard

[Back to the guide](README.md)

The home page. It answers "where does every space stand?" and is where you
start receipting and reporting for a space.

## What you see

One row per [space](concepts.md#spaces): a period, a riding (blank for
party-level and leadership), and an entity kind. Each row shows:

| Column | Means |
|---|---|
| Period | The EO period |
| Riding | The riding number, if the entity is riding-based |
| Entity | Party, CA, Campaign, or Leadership |
| Contributions | How many contributions are in the space |
| Open flags | How many open work items are on those contributions. Anything above zero blocks issuance. |
| Stage | Where the space is on the [stage ladder](concepts.md#spaces) |
| Stage owner | Who is responsible for moving it on, if set |

A riding-limited user sees only their own ridings' rows, plus party-level
ones.

## What you can do from here

- **Click the period** to open the [contributions list](contributions-and-payments.md)
  filtered to that space.
- **Issue** opens the [issuance wizard](issuing-receipts.md#issuing-a-whole-space)
  for the space.
- **Reports** opens the [entity reports](entity-reports.md) screen for the
  space.

## Things to know

- A space appears as soon as one contribution lands in it; there is nothing
  to create.
- The dashboard does not yet show an RTD deadline per space. RTD deadlines
  are on the [RTD filings](rtd-filings.md) screen.
